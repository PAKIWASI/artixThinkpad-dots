# artixthinkpad-dots

Dotfiles for my ThinkPad E14 running **Artix Linux** + **Hyprland**.

<img src="~/Pictures/Showcase/ss1.png" alt="Desktop" width="100%">

</div>

## Setup

| | |
|---|---|
| **OS** | Artix Linux |
| **WM** | Hyprland |
| **Shell** | zsh |
| **Multiplexer** | tmux |
| **Editor** | Neovim |
| **Browser** | Zen |
| **File manager** | Thunar |
| **Music** | Spotify |
| **Theme** | Catppuccin Mocha |
| **Fetch** | fastfetch (random pfp on launch) |

## Install

```sh
git clone https://github.com/PAKIWASI/artixthinkpad-dots.git
cd artixthinkpad-dots
```

Copy or symlink the configs you want into `~/.config`. Back up your existing ones first.
